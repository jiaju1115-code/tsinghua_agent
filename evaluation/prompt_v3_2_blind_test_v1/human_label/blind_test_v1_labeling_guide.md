# Prompt V3.2 Blind Test V1 人工标注指南

## 目的

请独立判断页面是否适合进入“清华校园知识库”。该知识库面向清华学生和校园相关用户，用于回答校园学习、生活、学生事务、公共服务、机构运行、校园资源，以及学生可利用的科研学术资源等问题。

不要推测或迎合任何模型结果。表中没有展示历史 AI 审核结果。

## 阅读材料

- 优先阅读 `cleaned_content` 中的完整正文；如需在编辑器中阅读，可打开 `content_file` 指向的 Markdown 文件。
- `category_hint` 只表示来源站点，`content_type_hint` 只表示标题呈现形式，不是审核结论。
- 只根据表内正文判断；不要因页面位于清华官网就自动保留。

## 标注顺序

### 1. 主题相关性

先忽略日期，判断页面核心主题是否属于需要的清华校园知识。

重点范围包括：

- 学习、教务、学籍、培养、考试和教学资源；
- 住宿、餐饮、交通、医疗、体育、场馆、校园访问和设施；
- 奖助、就业、国际交流、学生事务和管理规则；
- 图书馆、网络、邮箱、信息系统和校园公共服务；
- 清华职能部门、服务单位、机构职责和校园运行；
- 学生可利用的科研机构、实验室、平台、数据库、学术资源和科研机会；
- 稳定的清华基本信息、校园历史和资源体系。

如果页面只是科研成果新闻、获奖、人物报道、校领导活动、普通签约、普通讲座、普通活动或普通展览，通常主题相关性较低。

填写 `human_topic_relevance`：

- `high`：直接属于核心校园知识；
- `medium`：有一定关系，但稳定性、复用价值或主体边界需复核；
- `low`：只是新闻、人物、荣誉、活动或外部资讯，难以帮助用户理解或使用校园知识。

### 2. 时效性

只有主题相关时，再判断信息是否长期有效、当前有效、即将过期、已过期或无法确认。

填写 `human_time_status`：

- `evergreen`：长期稳定；
- `active_time_bound`：当前有效但有截止时间；
- `expired`：核心信息已经失效；
- `historical_but_valuable`：过去事件形成了现在仍存在的服务、制度、平台、资源或机构；
- `unknown`：正文无法确认当前状态。

正文明确写出截止日期时，可在 `human_valid_until` 填写 `YYYY-MM-DD`；没有明确日期则留空，不要猜测。

## action

- `approve`：主题相关，且当前或长期具有明显知识价值；
- `review`：确有边界，例如主题 medium、当前有效性不明、接近时效边界或持续性需核实；
- `reject`：主题本身低相关，或主题相关但信息已经失效。

## reject_type

只在 `human_action=reject` 时填写：

- `topic_irrelevant`：页面核心主题本身不属于目标知识库；
- `expired_event`：页面主题本来相关，但信息已经失效；
- `other`：极少使用，并在 `human_note` 中说明。

非 reject 页面请将 `human_reject_type` 留空。

## category

在 `human_category` 中填写最贴近页面知识含义的简短中文类别，例如“图书馆服务”“网络与信息化”“学生事务”“校园机构与部门”“科研参与与资源导航”“非目标范围”。

## 备注

`human_note` 简要记录决定性证据、边界或疑问。不要写模型推测。

## 完成前检查

- 50 条全部标注；
- action、topic_relevance、time_status 取值一致；
- reject 页面填写 reject_type；
- 日期只来自正文；
- 不修改 `blind_id`、`original_id`、正文和来源字段。
