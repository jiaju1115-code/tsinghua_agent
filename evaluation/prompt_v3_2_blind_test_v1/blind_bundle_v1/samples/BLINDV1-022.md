# Content

为落实保卫部“关于做好端午节假期校园安全工作的通知”及“关于开展‘安全生产月’活动的通知”要求，6月17日-18日，信息化技术中心、网络研究院组织对本单位在李兆基科技大楼、信息科学技术楼、建筑馆北楼的所属区域开展节前全面安全检查，覆盖办公室、库房、机房、演播室等各类重点区域。

此次检查重点包括房间内用电安全、接线板情况、灭火器配置、消防通道及杂物堆放等情况。检查结果各区域整体安全情况良好，针对部分学生工位卫生情况欠佳的问题，检查人员当场联系并督促相关人员完成清理。同时，检查人员还提醒各房间老师在假期离校前务必切断电源，消除用电安全隐患。

此前，信息化技术中心、网络研究院还通过微信群向本单位全体教职工转发保卫部相关安全提示，并在节前召开的交通安全培训会中强调了各类安全注意事项，强化师生安全意识。后续，信息化技术中心、网络研究院将继续落实各项安全管理措施，筑牢安全防线。
