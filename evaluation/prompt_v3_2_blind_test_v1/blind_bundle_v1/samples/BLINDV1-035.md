# Content

**一、服务介绍**

校园网络运行服务的主要内容是根据学校信息化发展需要，承担校园网络运行的相关工作，具体服务内容包括：

1. 有线网络接入服务：面向教学办公区、学生宿舍区和教工住宅区师生用户提供有线网络接入。

2. 无线网络接入服务：面向教学办公区和学生宿舍区师生用户提供无线网络接入服务。

3. 电子邮箱服务：面向全校师生提供个人电子邮箱服务。

4. 认证计费服务：面向全校师生提供个人上网认证和计费服务。

5. VPN服务：面向全校师生提供从校外访问校内资源的VPN服务。

6. 防病毒软件服务：面向全校师生提供企业版防病毒软件下载和特征库更新服务。

7. 网络安全服务：面向全校师生提供网络安全事件监测、研判、处理服务。

8. 联通固定电话服务：面向校内各单位提供联通固定电话业务、通讯管井管道维护。

**二、服务人员**

校园网络运行团队设为6个组，分别为网络运行组、系统运行组、机房运行组、NOC监控组、电信与工程技术组、项目管理组。其中网络运行组主要负责学校有线网络、无线网络和光缆通信网络的运维建设；系统运行组主要负责学校电子邮件系统、认证计费系统、VPN系统、校园网络安全保障系统运维建设；机房运行组主要负责校园网核心机房、主干节点机房、接入机房、设备间、弱电井的维护和安全管理；NOC监控组主要负责24小时监控校园网络及机房环境的运行情况；电信与工程技术组主要负责校园内联通铜缆电话、通讯管井管线的维护和管理；项目管理组负责校园网络运行室所承建项目和科研项目管理等工作。

**三、主要业绩**

1. 提供通达全校所有楼宇的光缆通信网络的服务

2. 提供覆盖教学办公区、学生宿舍区和校内教工住宅区的有线网络服务

3. 提供覆盖教学办公区和学生宿舍区的无线网络服务

4. 提供除蓝旗营、荷清苑外的校内教工宿舍区校园网GPON光纤入户服务

5. 提供校园网DNS、DHCP、计费认证、邮件及VPN等校园网络支撑服务
