# Content

4月22日下午，在清华大学110周年校庆即将到来之际，作为2021年度清华大学读书文化月的特别活动之一，清华大学图书馆音乐讲堂启用仪式暨石叔诚音乐讲座“黄河”在图书馆音乐讲堂举行。音乐馆施坦威钢琴捐赠者1998届校友部分代表、合作单位代表、音乐馆建设团队、校内师生和部分馆员参加了此次活动。图书馆副馆长张秋主持仪式。

图书馆党委书记蒋耘中出席仪式并致辞，他代表图书馆对所有支持图书馆音乐馆建设的老师、校友及合作单位表示衷心感谢。他说，图书馆音乐馆是学校开展大学生艺术教育、培养大学生文化素养的又一重要场所。音乐讲堂启用以后，将为我校师生开展音乐教学与欣赏提供服务，欢迎艺教中心以及学校其他院系的老师们来音乐讲堂开课、办讲座，组织各种艺术欣赏活动，充分发挥好音乐讲堂的作用。他希望大家继续支持音乐馆的建设和发展，把音乐馆建设成为清华大学艺术教育的响亮品牌。

音乐讲堂启用仪式结束后，进行音乐讲堂的第一场音乐讲座“黄河”。由我国著名钢琴家、指挥家石叔诚先生主讲。石叔诚先生声情并茂地讲述了如何参与创作“黄河”钢琴协奏曲，此曲的由来以及创作背后的故事，浓厚的历史色彩和中国精神，让读者感受到这首中国著名的钢琴协奏曲鲜明的民族性和文化底蕴。讲座中石叔诚先生穿插演绎的钢琴曲片段让大家体验了美妙的听觉享受，也令人建立了丰富的音乐形象，博得了读者的阵阵掌声。广大读者还与石叔诚先生展开精彩互动，我校键盘队同学上台现场弹奏，演绎不同风格的黄河协奏曲，得到了石先生的指导和赞许。石先生向图书馆捐赠了个人出版的书籍和音像资料，图书馆王有强馆长代表图书馆接受捐赠，并为石叔诚先生颁发了捐赠证书，赠送图书馆定制纪念品。

图书馆音乐讲堂正式开放，未来将安排音乐讲座、音乐演奏等活动，通过音乐的艺术表达形式，引导读者感受音乐的魅力，传播高雅音乐，搭建阅读与音乐的桥梁，培养现代大学生的音乐素养和阅读兴趣。
