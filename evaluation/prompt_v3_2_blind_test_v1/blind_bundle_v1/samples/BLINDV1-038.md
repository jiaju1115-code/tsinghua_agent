# Content

**一、服务介绍**

信息系统运行工作内容包括：承担我校数据中心的规划建设，以及信息系统运行维护工作,管理600多台各类服务器、网络、安全等设备、40多套数据库系统、43PB的存储数据以及290多个校级应用，为信息系统提供“安全、稳定、高效”的运行环境和“集成、共享、准确”的数据服务环境，为学校各院系部处提供“及时、准确、贴切”的技术服务。 服务内容主要包括：

1. 信息系统技术支持

对使用校级信息系统的各单位工作人员提供技术支撑。包括信息系统的使用培训和指导，业务数据核查、处理和统计，迎新、选课、注册等重大活动的技术支持，为系统尚不能实现的业务或深层次业务提供解决方案。

2. 信息系统应用管理

对校级信息系统应用程序及相应业务数据进行运行管理。包括应用登记与基本信息管理，应用运行规划与部署实施，日常监控与故障排查、运行分析及优化等。

3. 数据中心管理

负责数据中心服务器、网络、存储等设备运行维护，负责操作系统、中间件、数据库等基础软件环境维护，负责学校基础设施云平台、云盘等日常运行维护；负责学校公共软件更新和开源软件镜像站日常维护；负责学校信息系统数据备份管理。

4. 信息系统安全

负责信息系统从开发到运行全生命周期的安全管理，定期对校内信息系统进行安全扫描及渗透测试，处理各级各类平台发布的安全漏洞和安全事件，保障数据中心及信息系统的安全运行。

**二、服务人员**

信息系统运行团队现分为业务支持组、数据中心组和安全组。其中业务支持组负责校级信息系统的运行维护与技术服务，数据中心组负责学校数据中心的建设和运行维护，安全组负责信息系统的安全监测和管理工作。

**三、主要业绩**

1. 建立以流程为主线的运维管理体系

参照IT管理最佳实践，信息系统运行团队以“日常运维为根本，创新研究求发展”的管理思路，建立了以流程为主线的运维管理体系，将数据中心的建设与管理、信息系统的运行维护与服务、安全监测与管理等工作内容有机结合起来，采用相应的运维支撑工具及技术手段，建立了规范化的工作机制，保障了信息系统的稳定、安全、高效运行。

2. 建立了安全、稳定的信息系统运行环境

建立了安全、稳定、柔性的数据中心环境，为学校信息系统提供良好的运行环境。同时，建设了校级基础云平台，提供云盘、开源软件镜像等基础服务。

3. 实现信息系统运行全生命周期管理

在信息系统的全生命周期管理中，负责运行维护阶段信息系统的全面管理，面向信息系统的管理单位提供技术支持、应用管理、数据管理等日常管理与服务；同时参与信息系统的规划，负责信息系统运行方案的制定及实施。
