# Content

12月11日上午，校党委副书记过勇调研图书馆。

![](/__local/4/C3/E0/4E4CE65BFF584F1A0D62D5AB08F_F36C3182_14CC6.jpg)

调研座谈会现场

图书馆馆长金兼斌从图书馆的定位、高质量发展情况以及面临的挑战和问题等方面进行汇报。与会人员围绕人才队伍发展、资源建设、文化空间升级、教学条件改善等进行了交流。

在认真听取相关工作汇报和交流发言后，过勇表示，图书馆是清华最有历史的部门之一，在大学建设中具有重要地位，在支撑教学科研、传承大学文化中发挥了重要作用。图书馆要以“学”为中心，关注学生学习方式的变化，主动适应师生的需求。同时，理顺校系两级图书馆的关系，既要“办”好图书馆，也要“管”好图书馆。在数智化转型方面，希望图书馆能够起到示范引领作用，利用好学校的资源，赋能学校的学术研究。加强与各单位的合作，赋能学科建设。

座谈前，过勇参观了图书馆老馆以及“万卷琳琅——馆藏史部善本特展”。

图书馆班子成员、学术委员会及教学委员会主任、古籍特藏部及综合办公室相关人员参加调研。
