# Content

近日，Frontiers出版社、国家自然科学基金委员会（NSFC）科学传播与成果转化中心与中国教育图书进出口有限公司（CEPIEC）在北京正式签署三方战略合作协议。**此次合作紧扣国家 “十五五” 规划开放创新部署，旨在推动公共财政资助科研成果开放共享，进一步扩大中国高质量科研成果的全球传播与影响力。**

根据协议，三方将围绕公共资助研究论文的**开放获取、数据仓储服务以及科研诚信合作**等领域开展深度合作。作为合作的一项重要举措，**Frontiers将为所有获得国家自然科学基金资助的录用论文提供10%的文章处理费（APC）折扣**，具体生效日期将另行公布。

此次合作预计将助力国家自然科学基金委员会更有效地管理研究成果，加强其**开放获取仓储平台**的建设，并拓宽基金资助研究成果的传播范围和影响力。

**各方表态：共筑开放科学新生态**

**·** Frontiers首席执行总编Frederick Fenter表示，此次协议的签署是与中国科研界合作的一个重要里程碑，体现了各方对开放科学的共同承诺。他透露，未来的合作可能扩展到旗舰期刊出版、人工智能支持的研究数据服务以及研究诚信等更广泛的领域。

**·** 国家自然科学基金委员会科学传播与成果转化中心副主任李东强调，Frontiers在构建学术出版新生态、推动全球科研合作方面做出了重要贡献。他指出，此次合作将促进学术资源的开放共享，并提升国家自然科学基金资助研究成果的管理水平。

**·** 中国教育图书进出口有限公司董事长王建新认为，此次合作是服务国家战略需求的一项务实举措。他解释说，合作将聚焦于研究成果的国际传播、数据共享和研究诚信，既顺应国家优先发展方向和开放科学发展趋势，也与“十五五”规划的目标高度契合。

**合作意义：深化开放获取，服务国家创新**

此次三方联动，将为中国公共资助科研成果的开放获取、高效传播与国际化交流搭建更畅通的桥梁，为全球开放科学生态建设注入新动力。
