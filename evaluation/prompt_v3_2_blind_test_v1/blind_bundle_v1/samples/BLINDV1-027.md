# Content

《开放科学的经济效益》是PLOS（Public Library of Science，公共科学图书馆）“重新定义出版模式”计划的重要成果，它指出：**开放科学不仅是科研伦理的进步，更是驱动经济增长的关键引擎。**

该计划旨在探索学术交流的演变路径，以更大规模、更好地支持开放科学，包括**突破传统“论文”形式**，认可更多样化的研究成果，并构建更可持续的财务模式。

为此，PLOS委托评估机构Technopolis Group开展了此项独立研究。报告核心围绕以下三个问题展开：

- **开放科学的经济价值如何产生？**
- **实现这些价值需要哪些条件？**
- **当前面临哪些结构性障碍与成本压力？**

**报告概要**

**本报告探讨了开放科学的经济影响，以及推动构建一个将研究数据、代码、软件、工作流、方法和出版物等要素公开共享并加以重视的研究生态系统的所带来的意义。**报告于2026年3月发布，采用两阶段研究方法：

**(1) 快速证据评估：**对2022年11月至2025年4月期间发表的相关文献进行系统梳理，整合分散的经济证据。

**(2) 案例研究分析：**选取了五个具有代表性的案例，具体展示不同类型开放成果和基础设施如何创造价值，包括：

- 数字化科学馆藏（DiSSCo）
- 开源大语言模型（BLOOM）
- 计算工作流共享平台（WorkflowHub）
- 开源统计软件（R语言）
- 英国国家研究方法中心（NCRM）开放培训资源

**核心发现（六大要点）**

报告通过系统论证指出，开放科学通过支持研究产出的大规模再利用，能带来显著且可量化的经济效益。

**01 开放科学在实现大规模再利用时能带来显著经济效益**

当研究成果（特别是数据、代码、工作流、软件和培训资源）被设计并支持大规模再利用时，开放科学能够带来显著的经济效益‌。尤其在**减少重复工作、加速研究进程、实现跨社区和跨部门的下游应用**方面。

宏观经济模型表明，与采用开放科学实践的开放型研究环境相比，在采用封闭型研究模式的条件下，长期GDP增长率大约会**降低2%左右**。融入开放科学实践的开放体系更有利于经济持续增长。

**关键要点：**当系统环境支持再利用时，开放科学就能成为提升研究效率、促进经济长期发展的有效机制。

**02 最显著且可量化的效益来自效率提升**

**效率提升**是开放科学最直接、最常被量化的经济效益。

典型案例：数字化自然历史收藏为研究人员节省了数百万英镑的差旅成本；共享计算工作流平台WorkflowHub的使用价值（34.12亿英镑）远超其重建成本（429万英镑），效益成本比巨大。

**关键要点：**以效率为导向所带来的效益，更多地取决于对基础设施以及再利用条件的投入。

**03 开放基础设施促进创新并带来巨大衍生价值**

开放科学基础设施通过**支持开放资源（如开源软件、共享工作流、开放模型）的再利用、适配与扩展来推动创新**，其产生的下游价值常远超初始投入。例如开源大语言模型BLOOM的使用价值估计是其训练成本的十倍以上。

**关键要点：**开放科学基础设施可以成为推动创新的赋能平台，持续的应用与维护是释放其经济价值的关键。

**04 网络效应使开放科学的效益随时间累积增长**

许多开放资源（如共享工作流、开源软件生态系统）会随着越来越多的用户采用、贡献和再利用而不断提升其价值，更广泛的参与能促进再利用并加速累积性创新。

**关键要点：**网络效应的存在强化了对开放科学进行持续且协同投入的必要性，而非零散或短期的投入‌。

**05 成本在利益相关方之间分布不均，阻碍了规模的扩大**

开放科学的成本分配并不均匀：

**(1) 研究者：**承担时间和技能成本（数据整理、代码文档、合规性工作等）。

**(2) 图书馆及其他基础设施提供商、存储库运营者：**承担长期保存数据的责任

**(3) 出版商：**投入资金来建设相应的平台和工作流程，支持不同类型的科研成果输出。

相比之下，开放科学带来的益处则惠及**整个社会**，且不受国界限制。这就导致了付出成本的一方与受益一方之间的失衡现象。

**关键要点：**成本与收益的不匹配限制了开放科学的扩展，需通过协调机制与激励措施应对。

**06 开放科学的经济价值被系统性低估**

开放科学具有显著的经济效益，其影响可以量化，尤其体现在开放成果的再利用及其下游应用中，但目前在整个系统中如何**衡量开放科学的再利用、网络效应及长期价值**方面存在差距，与获取更广泛的经济和社会价值相匹配的机制仍然有限，导致当前评估可能仅反映开放科学创造的部分价值，并造成对那些能带来最大长期回报活动的投入不足。

**关键要点：**加强衡量对于拓展和深化开放科学价值的评估，以及将政策、资金和激励机制与经济价值的产生相匹配至关重要‌。

**建议与行动路径**

**系统投资支撑体系：**协同投资共享基础设施、通用标准与配套激励机制，以促进跨边界再利用，充分释放效率收益。

**发挥资助者在解决成本错配中的关键作用：**资助机构应通过统筹激励政策与共享性基础设施投入，着力化解成本承担与收益分配不匹配的问题。

**加强对经济与社会价值的衡量与评估：**建立统一、可持续的经济与社会价值测量体系，为政策优化与资源投入提供证据基础，引导支持向高价值领域聚焦。
