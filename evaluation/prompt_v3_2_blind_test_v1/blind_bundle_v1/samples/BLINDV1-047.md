# Content

11月21日，期刊编辑进校园——*Science*专场活动在图书馆举行。活动特别邀请*Science*期刊资深编辑江涤作主题报告。科研院科技成果与奖励办公室主任孟宪飞、*Science*出版社北京办公室项目经理赵丹出席活动。活动由图书馆党委副书记窦天芳主持，100余位师生以线上线下相结合的形式参加活动。

![](/__local/9/49/F8/44B7C874334FFDC2C5963CB9C89_B76D81B1_9B86F.png)

活动现场

江涤简要介绍了*Science*的发展历程、年度稿件处理及发表的基本情况。他特别指出，*Science*作为美国科学促进会（AAAS）官方刊物具有鲜明的非营利属性和多学科特点，承担科学论文发表与科学新闻报道的双重使命。他详细介绍了*Science*“聚焦突破性科学发现”的定位，并结合具体案例，重点阐释了投审稿流程和论文可读性要求等内容。现场师生踊跃提问，江涤就投审稿环节遇到的实际问题与现场师生深入交流，并建议研究者在撰写研究型论文时应保持严谨的学术态度，坚守科学研究与科学传播的初心，避免“为发表而发表”。

观众提问

窦天芳在开场主持时指出，图书馆作为学术传播体系中的重要一环，将协同校内相关部门持续办好高水平编辑进校园系列活动，统筹推进高质量出版与学术传播，帮助师生了解国际顶尖期刊的出版流程和出版规范，助力学校高水平科研成果的国际传播。

期刊编辑进校园系列讲座活动由图书馆、科研院、教师发展中心联合主办，致力于为我校师生搭建与国际高水平出版机构交流沟通的桥梁，助力学校高质量发展。
