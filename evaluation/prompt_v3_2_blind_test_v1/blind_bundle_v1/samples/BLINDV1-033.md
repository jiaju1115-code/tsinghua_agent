# Content

2月27日，清华大学图书馆馆长金兼斌与朱拉隆功大学学术资源办公室/图书馆主任Amorn Petsom分别代表两校图书馆在泰国朱拉隆功大学图书馆展览厅签署合作备忘。清华大学党委副书记过勇和朱拉隆功大学校长Wilert Puriwat出席签约仪式并致辞。

![](/__local/3/B3/86/01A431B07A6E4A788652F675761_5E175AC0_25358.jpg)

近年来，清华大学图书馆积极开展同包括朱拉隆功大学图书馆在内的多家海外知名大学图书馆的交流和合作。本次两校签署的合作备忘，涉及馆员能力建设、共同举办会议或论坛、馆际互借等，旨在共同应对数智时代大学图书馆面临的各种挑战，更好发挥图书馆作为大学学术资源中心和创新基础设施的关键支撑作用。

过勇副书记代表清华大学致辞。他介绍了清华大学的全球发展战略，强调东南亚是清华全球布局的重要地区，清华重视发展同朱拉隆功大学和其他泰国大学的多种形式的深度合作。他表示，这次签约标志着两校间合作又迈出了重要一步，两校的学术交流和合作的框架和目标更加清晰。Wilert Puriwat校长强调，这次签约并不只是两校图书馆之间的合作交流，而是两个大学之间的深化学术交流的契机。

金兼斌在发言中回顾了去年朱拉隆功大学图书馆代表团对清华大学的访问。他表示，此次合作备忘录所涉及的三方面的合作内容，都经过双方前期的多次讨论和确认，具有很高的可行性。他希望和朱拉隆功大学的图书馆同仁一起，努力让备忘录所勾画的合作前景付诸实现。

清华大学新闻与传播学院院长周庆安、美术学院院长吴琼、亚洲大学联盟秘书长刘健、国际处副处长匡恺等及朱拉隆功大学学术资源办公室副主任潘松等代表一同出席备忘录签署仪式。
