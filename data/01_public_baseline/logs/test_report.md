## 特殊情况与已知问题

- 清华主页包含较多栏目卡片、轮播和图标字体，Trafilatura 能保留主要可见文字，但会出现少量图标乱码、数字重复和栏目噪声。
- 首页、栏目页、机构主页的正文边界比文章详情页弱；第一轮“宁可多抓”策略下仍会保存部分这类页面。
- 本次认证检测到 `info.tsinghua.edu.cn`，已写入 `auth_required.csv`，没有绕过或提交凭证。
- `jobs.tsinghua.edu.cn` 和 `mails.tsinghua.edu.cn` 因无足够可提取正文被跳过。
- 本次样本没有确认必须由 JavaScript 才能获得正文的页面；代码当前也未启用 Playwright fallback。
- 本次没有发现登记范围内的大量 PDF/Office 附件，不能据此判断全量站点的附件规模。
- 当前已尊重每站点 `robots.txt`，但第一版尚未主动解析 sitemap 索引；URL 发现主要来自种子和页面内部链接。这是正式扩量前应补齐的能力。
- 当前内容去重是精确 SHA256，能处理完全相同正文；“高度相似”页面尚无 SimHash/MinHash 等近似去重。
- 分类提示是保守关键词提示，主页中的“新生”等词可能造成误分类；它仅是 hint，不用于丢弃页面。
- 运行环境的 Conda 在进程结束时报告 `conda-libmamba-solver` 插件警告，与采集器运行和输出无关。

## 正式扩大前建议

1. 增加 sitemap/robots 中 Sitemap 声明的受控发现，并限制 sitemap 数量和 URL 上限。
2. 针对清华主页模板增加站点级正文容器与页脚清理规则，重点处理图标字体、重复数字和公众号/版权尾部。
3. 增加近似内容去重，但只登记重复，不自动删除已存在主文档。
4. 增加 URL 优先级队列，让校园服务、新生、图书馆、后勤、校医院等词命中的 URL 优先于科研栏目，同时保持广覆盖。
5. 在人工确认公开性后，对少量正文为空的 JS 页面加入按需 Playwright fallback；不要默认对每页启动浏览器。
6. 先补充并人工验证校园服务相关种子，再把 `test_mode` 改为 `false`；首次正式批次建议先设 300 页观察限流与正文质量，不要一步直上 3000。
