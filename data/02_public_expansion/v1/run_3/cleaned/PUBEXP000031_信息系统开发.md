# 信息系统开发

一、服务介绍

信息系统开发服务的主要内容是根据学校信息化发展需要，负责清华大学信息系统的研究、设计与开发工作，主要承担了清华大学基础数据管理系统、信息门户系统、教务系统、学生系统、财务系统、党员系统、纪检系统等项目的建设开发任务，覆盖了清华教学、学生、党员、财务等业务领域，有力地支撑了学校人才培养、社会服务等工作的开展。

二、服务人员

信息系统开发团队按业务分为教学学生业务、人事组织业务、财务设备后勤三个业务系统工作组，负责对应部门信息系统的开发维护工作；另设有平台与架构、UI设计与前端开发、过程与质量管理三个平台工作组，负责为业务系统工作组提供公共基础服务支撑。

三、主要业绩

1. 信息系统整体架构的设计

信息系统开发团队主要基于数据层、公共服务层、应用层、用户层四个结构层次为用户提供服务。数据层着重实现数据集成与共享；公共服务层提供公共服务接口，最大程度实现软件复用；应用层着重实现业务功能；用户层面向各类用户提供个性化的信息服务。通过建立松散耦合的信息系统整体架构，促进了数据保持一致和充分共享，降低了信息系统建设成本，实现快速响应业务需求，面向不同用户提供差异化信息服务。

信息系统开发团队先后自主开发了信息门户、身份认证、权限管理、日志管理、文档管理、日历服务等公共软件平台和组件，实现了应用系统的快速开发。

2. 信息门户建设

信息系统开发团队承担了清华大学信息门户建设项目，升级技术架构，提高系统性能、可靠性、可扩展性，引入搜索引擎、AI计算、消息队列、大数据框架，提升用户使用体验，实现统一校内信息发布，支持应用深度集成，提供个性化、智能化服务 。

图1 清华大学信息门户系统

3. 业务系统建设与开发

信息系统开发团队承担了学校主要业务系统的建设任务，先后自主开发了教务管理系统、网络教学系统、学生管理系统、人力资源系统、组织党员系统、财务信息服务系统、外事管理与服务系统、实验室与设备管理系统、纪检系统等业务系统，为学校师生用户的日常学习和工作提供服务，其业务层面基本覆盖了学校的主要管理部门 。

图2 清华大学主要业务信息系统

此外，信息系统开发团队成立信息系统维护开发组，对进入运行状态的信息系统持续进行维护性开发，保障业务运行，提升用户满意度 。

4. 信息技术研究

信息系统开发团队不断跟踪互联网与信息技术的发展，并将其应用到清华大学信息系统的建设中。从C/S架构系统到B/S架构，从独立业务系统到企业级的信息系统整体架构，新技术的应用极大地推进了学校信息系统的建设和应用。

随着人工智能技术的快速发展，信息系统开发团队积极学习并应用人工智能技术，在新版信息门户中集成清小助和清小搭，提供智能问答服务；试点自主研发二级单位智能问答系统，探索在业务系统中集成智能服务的方式；试点应用AI编程辅助工具，提高信息系统开发效率。

5. 近期项目成果

信息系统开发团队承担学校立项和部门委托的信息系统建设项目，在支持教学、服务师生、支撑管理和保障安全等方面取得良好的应用效果 。

图3 信息系统应用效果

（1）支持教学

网络学堂持续完善和升级，增加在线课表、在线批注、课堂问卷、出勤记录等功能，支持线上线下融合式教学，新增扫码考勤功能，优化学生端用户界面，开发学生学习任务汇聚列表功能，方便学生整体掌握需完成的学习任务，并快速进入相应系统功能完成学习任务。系统运行稳定，用户反映良好，有力保障了学校教学工作的开展。

启动新版综合教务系统建设工作，建立满足个性化培养、本硕博贯通培养、交叉培养教学需要，支持多维度、多层级教学管理，集决策、管理、服务、评价于一体的，具有开放性和可扩展性的教学管理系统平台。

以“满足当前，兼容历史，适应未来，稳定为先”的设计原则制定和优化实施方案，以适应国家研究生学科专业目录调整的要求，保证了2024级研究生招生、培养和学位授予工作按新目录进行，在校生及2023级研究生对应的培养和学位授予仍按原学科专业进行。

适应工程师学院跨类别、跨院系开展研究生教育管理的业务需要，实现涵盖研究生学籍、交费、注册、培养、选课、考试、成绩、论文查重、全过程培训等培养环节主题信息查询服务。

（2）服务师生

完成信息门户升级，优化搜索、新增智能问答；新增列表式导、常用导航；持续推进常用应用待办事项集成；完成移动端优化升级，PC和手机端功能基本一致，方便师生快速进入办事入口。

财务报销服务再升级，北医三院门（急诊）公费医疗实现报销“免跑腿”。

完成资金结算管理与服务平台二期，实现校内收费项目管理、B2B收费、二维码收款，为全校对公和对私资金提供网上支付和网上转账服务，覆盖面不断增大，支付接口访问次数、交易次数和交易金额逐年递增。

开发“无纸化投递”系统。师生零跑腿，实现银行代发。

完成研究生教育管理过程风险预警提醒平台建设，支持培养、学籍预警事项的配置，协助研究生院完成学业异常名单排查。

（3）支撑管理

组织党员系统实现组织生活和党员发展全过程纪实，支持银联和微信在线缴纳党费等功能，实现党组织和党员管理工作的全面信息化。

学生资助奖励系统覆盖本科生、研究生奖学金、助学金、借贷款、勤工助学、困难补助、补偿代偿等学生资助工作全业务、全过程。

辅导员全周期培养与管理系统覆盖全校辅导员、德育助理设岗、聘岗、选课、活动、荣誉、发展全过程培养与管理。

对我校校级科研条件平台能力体系进行系统梳理并支持动态管理，形成我校校级科研条件平台能力体系知识图谱，方便师生查找和使用学校大型仪器，宣传我校校级科研条件平台的人员队伍建设和能力体系建设成果。

建设统一的个人收入管理系统，替代原有7个系统11个数据库，实现一体化管理，支持多账套、多法人主体发放个人收入，实现在不同法人主体给同一个体发放个人收入时采用不同计税模式，满足不同主体、收入发放场景的业务需求。

（4）保障安全

电子身份认证系统为全校400多个业务系统提供电子身份认证服务，实现双因子认证，支持短信验证码、微信验证码和TOTP动态码等多种双因子验证方式，提升全校师生账号的安全性。

新增统一登录功能，支持用户在可信浏览器一次登录即可登录访问学校的业务系统，简化登录操作。升级用户登录权限管控功能，支持细粒度地按用户组给用户授权登录应用，支撑学校精细化的信息资源配置管理工作。

关闭业务系统的独立登录入口，改成使用统一身份认证系统登录界面，不仅保证业务系统不接触用户密码规避泄露密码风险，而且使用双因子认证保障账号安全。

新增实名认证功能。清华账号用“国家网络身份认证”APP 绑定实名认证信息后可用该 APP 扫码登录以及重置清华账号口令。扫码登录服务避免在公用机输入账号及口令，提升账号安全性。实名认证扫码重置账号口令为用户提供便利。
