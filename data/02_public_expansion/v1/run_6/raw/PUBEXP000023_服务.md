# 服务

借还规则

借书

读者服务台：位于美术学院大楼A座美术图书馆一层，办理本馆中外文图书的借阅手续，解答一般咨询问题。

本馆出口处设有自助借书机，可供读者自助借书。

美术图书馆图册闭架借阅库图书实行预约外借服务模式。请读者提前通过“水木搜索”进行系统预约，馆员准备好预约书，系统自动通知读者来馆取书。

读者可根据需要自行在图书馆主页网上续借或自助借书机进行续借。

还书

1、在美术图书馆读者服务台人工还书。

2、校图书馆总馆、文科图书馆、美术图书馆、法律图书馆、金融图书馆、经管图书馆、建筑图书馆之间实行图书通还服务，读者可就近选择图书归还地点。

特别说明

1、美术图书馆闭架图册库图书，还书地点仅为本馆读者服务台。

2、在校图书馆总馆、文科图书馆、法律图书馆、金融图书馆、经管图书馆、建筑图书馆归还的美术图书馆图书，如在“转运”状态，须等图书通还至本馆后方可借阅。如无特殊情况，一般在下午3点前后运回本馆。

特别提示：

1、读者记录冻结、有过期图书、欠款超过限额的情况下无法借书、续借、预约。

2、外借中图书接受续借和预约。

在其他读者预约的情况下，图书管理系统将对借期为28天以上的图书执行催还。

3、预约图书前，请确保本人已成功开通借书权限。

预约书回馆后在预约架上保留3天，期间图书馆会向读者发出预约取书通知。

4、过期图书、被预约图书不接受续借。续借期图书如有其他读者预约，系统将调整还书日期。

更多相关信息，详见校图书馆主页图书借还。

逾期使用费

对未能在规定日期之前归还图书的读者，将按以下标准进行收费。

|  |  |
| --- | --- |
| 借期类型 | 金额 |
| 8周 | 0.20元/天 |

读者有义务准确了解借阅规则，并主动按时归还所借图书。图书馆向读者发送的流通通知只是善意提醒，请勿将流通通知作为还书依据。

缴费方式：

在线缴费：读者通过登录图书馆主页的“我的图书馆”可随时缴纳与图书相关的费用（操作方法可参照“如何使用在线支付”）。

线下缴费：读者可在北馆、文科图书馆、美术图书馆、金融图书馆、经管图书馆、建筑图书馆和法律图书馆通过一卡通学生证自助缴费；北馆一层总服务台结算处同时提供微信/支付宝支付、POS机刷银行卡和现金支付等缴费服务方式。

遗失赔偿

读者遗失或污损美术图书馆书刊需进行赔偿。损毁、污染馆藏书刊应按损污程度进行赔偿，损污严重无法继续提供公众使用的按遗失书刊进行赔偿。

预约馆内阅览服务

美术图书馆图书闭架库、过刊闭架库书刊实行预约馆内阅览服务模式。

请读者提前通过“水木搜索”进行系统预约，馆员准备好预约书，系统自动通知读者来馆取书。

读者收到通知后，可尽快携带本人证件到美术图书馆读者服务台办理押证馆内阅览手续。

读者当天未看完的书刊可在服务台保留三天。

文印服务

美术图书馆在二楼北部设有自助文印设备，可以进行自助复印、打印、扫描等。自助文印服务更多资料请参考：<https://lib.tsinghua.edu.cn/kj/zzfw1.htm>。

服务时间：开馆期间；服务电话：62798810

更多内容参见校图书馆主页自助服务。
