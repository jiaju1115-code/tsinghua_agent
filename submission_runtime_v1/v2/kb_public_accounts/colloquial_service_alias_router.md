# 清华校园服务口语同义映射与高召回检索提示

这张卡用于帮助检索器把生活化问法改写成知识库中的业务词。它只负责召回，不直接替代具体办理规则。

## 访客与校门

- **固定优先映射**：出现“我爸妈、我父母、我家长、我亲戚、我亲友、我朋友来找我/来学校/来清华”时，优先追加 `亲友来访报备、学生访客预约、行在清华、清华大学信息门户、在线服务系统`；不要默认追加 `校园参观、游客预约`。
- **游客映射**：出现“游客、旅游、参观清华、打卡、逛校园、社会公众”且没有“我/校内师生/亲友/朋友来找我”等接待关系时，追加 `校园参观预约、参观清华、campusvisit`。
- **工作映射**：出现“单位接待、因公、老师邀请、学术来访、工作来访”时，追加 `工作来访、临时出入校园人员报备、在线服务系统`。
- 能不能进、怎么进、带身份证、门口登记、预约一下 → 校门通行／来访报备；如含今天、明天、现在、是否开放，再追加 `当日开放、暂停报备、最新公告`。
- 带车来、开车进、车怎么进 → 来访车辆预约／行在清华／校门交通。

## 体育场馆

- 游泳馆怎么进去、学校游泳池、想游泳 → 游泳馆入场／体育场馆预约。
- 羽毛球、篮球、网球、健身房订场 → 场地预约／清华大学体育场馆中心。

## 信息化与校园卡

- 网费、校园网、宿舍断网、续费 → 校园网缴费／信息化服务。
- 密码、VPN、邮箱、云盘、企业微信 → 清华大学信息服务／账号服务。
- 卡丢了、补卡、校园卡不能用 → 校园卡挂失与补办。

## 餐饮与权益

- 湖南口味、湘菜、辣一点 → 食堂推荐／紫荆园／川湘风味／食在清华。
- 好吃又便宜、吃什么、哪个食堂开 → 饮食服务中心／食在清华／当期营业信息。
- 生活问题、食堂反馈、快递自提、权益问题 → 艾生权／小艾在现场。

## 使用规则

检索时先执行固定优先映射，再保留原问题并由模型补充少量业务词和账号名；固定词典用于防止口语称呼被改写到错误实体，模型动态改写只能扩展，不能覆盖或反转已命中的强关系规则。先用知识库证据回答，若问题含“今天、明天、当前、最新、能否、是否开放”等时效词，应优先寻找最新公告或联网搜索结果，并明确来源和时间。没有证据时不可凭别名卡臆造具体流程。
