# 清华校园服务公众号与组织信息入口

这是一张“遇到某类校园问题该去哪里查”的导航卡。它不代替各账号当期推送；涉及今天、当前营业、临时施工、具体活动名额和截止日期时，应以账号或所属部门的最新公告为准。

## 综合生活与权益：艾生权

- **艾生权**是清华学生会生活权益相关的信息发布与权益服务平台。它适合查收与学生日常生活、食堂、教学安排、施工占道、校园服务和权益反馈有关的通知。
- 校方和相关政府公开材料均将“艾生权”列为面向师生开展校园生活、节约倡议等信息传播的渠道。用户说“艾生活有什么通知”“学生权益问题去哪看”时，可优先建议关注该渠道的当期推送。
- 它发布的是综合通知入口，不应把某一篇历史推送当作永久规则。例如暑假食堂安排、临时施工和某次活动报名都须看当期日期。

## 餐饮：食在清华

- **食在清华**是饮食服务中心引导关注的官方餐饮服务公众号。适合查食堂上新、营业调整、美食活动、线上餐卡充值及当期菜品相关信息。
- 用户问“今天哪个食堂开”“某窗口有什么菜”“具体多少钱”时，应优先查看“食在清华”当期信息，而不是根据历史美食推送猜测。

## 安全、校门与交通：平安清华／行在清华

- **平安清华**和**行在清华**是保卫部在新生安全提示中明确推荐的安全与校园通行信息渠道。
- 适合查校园安全提示、道路施工与通行变化、校门与来访车辆预约、外卖／快递电动车登记等事项。
- 来访车辆的预约由校内单位通过“行在清华”办理；具体是否开放、预约门和时段可能变动，必须以当期规则为准。

## 宿舍与学生社区：清华家园网

- **清华家园网**由学生社区管理服务中心提供。可用于查看社区服务通知、公告、报修、水电相关服务、公寓公共空间预约、社区课堂报名和垃圾分类督导预约等。
- 对新生，它还提供新生通道、住宿相关指引及部分住宿服务；具体入口和截止日期以当年新生通知为准。

## 社团与活动：清华大学学生社团

- **清华大学学生社团**微信公众号（微信号：**THUXSST**）由校团委社团部相关体系提供活动和社团资讯入口。
- 截至校方公开资料所述，学校有多个类别的注册学生社团；用户想找社团活动、百团招新、加入社团或了解社团动态时，应引导其查看该账号的最新活动信息或联系社团部邮箱 `shetuan@mail.tsinghua.edu.cn`。

## 回答规则

- 先用用户的自然说法匹配到服务域：如“吃什么/食堂”→食在清华；“路能不能走/车怎么进”→行在清华；“宿舍坏了/公共空间”→清华家园网；“想参加社团”→清华大学学生社团；“生活通知/权益问题”→艾生权。
- 对账号本身能确认的功能可以直接回答；对账号中某一条动态内容，必须附带“查看当期推送”的提醒，不能编造最新状态。
