# 清华官方及学生组织公众号/微信小程序功能目录

## 识别原则

公众号名称不一定包含“清华”二字。只要账号介绍、清华官网组织页面、二维码说明或菜单说明出现“清华大学”“清华官方”“校研究生会/学生会/团委指导”等身份线索，就应把账号及其稳定功能纳入检索候选；但不能仅凭名称相似就把账号认定为官方账号。近期推文中的日期、价格、开放时间和活动安排仍需按原文时间线核验。

## 口语问题映射

- “饭卡怎么充值”“一卡通怎么充钱”“校园卡余额怎么查” → **清华校园卡**，优先回答微信搜索小程序 → 个人中心 → 充值；不要回答成校园网充值。
- “紫荆码在哪里”“怎么进楼出示什么码” → **清华紫荆**，说明首次使用可能需要统一身份认证。
- “研究生会有什么生活服务”“哪里反馈宿舍/校园生活问题” → **水木汇 THU** 或校研究生会生活部，给出求助/点评/友货等功能边界。
- “研究生体育活动/俱乐部在哪里报名” → **清动圈 THU**、`thu体育俱乐部`，不要把活动新闻当成长期规则。
- “清华学生会/研究生会公众号有什么用” → 先按学生组织服务账号回答；若用户给出“清研阁”等名称，作为待核验别名搜索，不自动等同于“清研学术”或其他账号。

## 账号与功能扩充规则

1. 优先抓取账号介绍、菜单、服务入口、办事说明和长期栏目；这些内容比单篇活动新闻更适合进入知识库。
2. 文章中出现“清华大学”“校团委指导”“校研究生会运营”“官方平台”等身份线索时，保留来源与原文链接，并记录账号名、主体、服务对象和可执行入口。
3. 只把活动日期、报名截止、价格、临时开放等信息作为带日期的动态证据；回答当前问题时必须检查时效。
4. 不把第三方转载、营销内容或无法核验的同名账号当成清华官方事实；可以作为“待核验线索”而不是答案依据。
