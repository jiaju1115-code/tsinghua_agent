# 网络检索回退：接入准备状态

## 当前事实

截至 2026-08-18，当前清小搭项目没有已安装的插件，V3 草稿也没有
网络检索节点。因此它只能使用知识库，不能在知识库不足后自动联网。

已在清小搭插件市场发现 **博查搜索**（Coze Official）：其说明为全网
网页搜索与链接检索，适合作为证据不足时的备用检索工具。但该账号界面
显示“未授权”，所以本文件不把它写成已经可用的能力，也不尝试代替用户
完成第三方授权。

## 授权后的目标分支

```text
语义检索改写 -> 知识库检索 -> 证据判定
                                  | SUFFICIENT -> 直接回答
                                  | PARTIAL    -> 已知部分 + 官方查证方向
                                  | INSUFFICIENT / 强时效
                                      -> 博查搜索
                                      -> 结果来源筛选
                                      -> 基于网页证据的回答
```

网络结果不能直接作为无条件答案。优先接受清华官方域名、清华直属单位站点和
明确归属清华官方账号的公开文章；对新闻转载、学生媒体、历史文章和商业评价
仅能用作线索或主观推荐依据，并标明时效/来源边界。搜索无官方证据时仍应
明确说明无法确认，不能把搜索摘要当作校规。

## 推荐的首批来源范围

- `www.tsinghua.edu.cn` 及直属单位页面；
- 清华饮食服务中心及其唯一官方服务号“食在清华”；
- 清华大学图书馆、医院、研究生院、学生社区/后勤等公开服务页面；
- 学生会权益信息平台“艾生权”的公开文章，作为学生生活线索，涉及当日
  政策时仍须回到校方或主管部门的当期公告核验。

## 安全与时效规则

- “今天、现在、最新、是否开放、截止、价格、菜单”等问题必须带来源和
  检索时间，不能复用历史文章来确认当日状态。
- 不把需要登录、个人信息、校内账号或非公开网页加入公共知识库。
- 只保存解决问题所需的结构化事实、原始链接、发布日期/抓取日期和适用
  边界；不批量复制公众号全文。
