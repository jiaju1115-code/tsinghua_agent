# 清华大学亲友来访报备、工作来访与校园参观区分说明

先判断来访者与提问者的关系，**不要把“亲友来访”默认回答成“游客参观”**：

1. **校内师生的爸妈、亲属、亲友、朋友来找自己**：首选“亲友来访报备”。由校内师生在“行在清华”小程序或清华大学信息门户/在线服务系统内的亲友来访报备入口填写来访信息；来访人按报备有效的证件和当次校门查验要求入校。这是“我爸妈来学校”“朋友来清华找我”“亲戚来看我”的默认路径。
2. **因工作、学术、单位接待而来访**：使用工作来访/临时来访人员报备，可能需要接待单位审批；不要用亲友报备替代。
3. **与校内师生无接待关系、目的只是游览校园的社会公众**：才使用“参观清华”的公众校园参观预约。个人参观可通过“清华大学”公众号的“参观清华”菜单实名预约，官网为 https://campusvisit.tsinghua.edu.cn/ 。

“明天爸妈来学校还能正常预约进校吗”应先回答：由学生本人走亲友来访报备；但“明天”属于动态状态，是否开放、名额/上限和校门要求以“行在清华”或信息门户当日页面、保卫部门最新通知为准。校园活动期间可能暂停或调整亲友报备，不能以游客预约结果代替。

公开保卫部门通知可佐证：临时来访人员通过在线服务系统报备；相关通知也单独使用“亲友来访报备”这一类别。校庆和新生报到等特殊期间会另行设置或暂停特定报备通道。

校园参观咨询电话：010-62793001。

## 回答边界

1. 问“我爸妈/亲友/朋友来找我”时，优先说亲友来访报备，不先推荐校园参观。
2. 仅当用户明确是游客、参观、打卡、社会公众且无校内接待关系时，才推荐“参观清华”。
3. 不可根据学生公寓来访时间推断家长能否进入整个校园。
4. 用户问“今天/明天/现在能不能进”时，必须提示其核验报备系统或最新公告，不猜测当日状态。
