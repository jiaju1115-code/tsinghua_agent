# Pilot evaluation plan

Run the existing frozen/reference evaluations before and after the remote pilot. Compare General overall, mathematical reasoning, general instruction, linear algebra, calculus, probability/statistics, reasoning, and code; then Campus QA, grounding, evidence sufficiency, citation support, refusal, unsupported-claim, and hallucination metrics. Thresholds are provisional and experimental: General should improve while Campus grounding and safety must not show a clear regression. No test set is created from the 841 candidates.
