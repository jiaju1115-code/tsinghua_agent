# Local RAG vs Web Search diagnostic

| Dimension | Local RAG | Web Search V0 |
|---|---|---|
| Best use | Stable, reviewed campus corpus | Fresh public information and source gaps |
| Strength | Low latency, stable provenance | Timeliness and broad coverage |
| Constraint | Cannot cover newly published sources | Variable latency, availability and source quality |

The systems are complementary. This diagnostic does not replace or modify Local RAG.
