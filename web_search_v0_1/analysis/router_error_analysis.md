# Router error analysis

Frozen 30 regression was 30/30 correct. The independent Academic Shadow Set was 16/24 correct (66.67%).

The eight Shadow router errors are S03, S09, S10, S13, S15, S18, S21 and S22. They expose missing vocabulary/structure coverage for constrained optimization, conditional probability, confidence intervals, energy/momentum, fixed effects, dynamic programming and graph traversal.

After the Shadow run, one required semantic-priority compliance test from the stage specification was added: a recognized subject plus an exam/problem formulation outranks a year token. The Shadow set was not rerun and is therefore explicitly retained as a **pre-change provisional regression result**, not a post-change validation claim.
